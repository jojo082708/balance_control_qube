# QUBE-Servo 3 — 倒單擺 × 阻抗控制平滑切換系統

實驗室專題：QUBE-Servo 3 擺桿附件的倒單擺起擺 / 平衡控制，穩定後可由使用者
一鍵無縫切換至旋臂阻抗控制，進行人機互動與動態響應測試。

---

## 專案目標

系統以狀態機整合兩種截然不同的控制律：

1. **倒單擺控制**（Swing-up + LQR Balance）— 將擺桿從自然下垂甩至正上方並穩定平衡。
2. **阻抗控制**（Impedance Control）— 平衡達成後，使用者可按下按鈕，將旋臂控制權
   平滑（bumpless）轉移至阻抗控制律，讓旋臂像虛擬彈簧-阻尼系統一樣回應外力：

```
M · θ'' + B · θ' + K · θ = F_ext
```

透過調整 **K（剛性）**、**B（阻尼）**、**M（虛擬慣量）** 三個參數，
可以改變旋臂對外力的回應特性，而不需要更換實體機構。

切換僅在倒單擺穩定於頂端（角度與角速度皆在容許範圍內、且持續 N 個週期）時致能，
避免硬體損壞或馬達暴衝；切換後系統忽略擺桿掉落，直到使用者手動重置。

## 使用說明

1. 確認 QUBE-Servo 3 已連接並開機、**擺桿附件已安裝**
2. 執行 `python main.py`
3. 調整左欄的阻抗參數（K / B / M）和 PD 增益（Kp / Kd）— 於阻抗模式生效
4. 設定實驗時長和次數
5. 按「▶ 開始實驗」— 系統自動起擺並嘗試平衡擺桿
6. 擺桿穩定於頂端（狀態機指示燈：綠燈「已平衡」）達 N 個週期後，
   「⇢ 切換至阻抗控制」按鈕會由反灰轉為可按
7. 按下該按鈕，旋臂控制權平滑轉移至阻抗控制（藍燈「阻抗控制中」），
   即可對旋臂施力測試阻抗響應
8. 阻抗模式期間如需返回起擺，按「↺ 重置系統」
9. 任何時候按「■ 停止」立即切斷馬達輸出（最高優先權緊急停止）
10. 實驗完成後按「⬇ 儲存 Excel」匯出資料（含 `mode` 欄位標示每筆資料所屬狀態）

## 倒單擺狀態機

```
   ┌──────────┐   擺桿接近頂端(±10°)    ┌──────────┐
   │ Swing-up │ ───────────────────▶ │ Balance  │
   │  起擺    │ ◀─────────────────── │  平衡    │
   └──────────┘   擺桿掉出容許範圍     └────┬─────┘
                                            │ 穩定 N 週期(±5°, |ω|≤0.5rad/s)
                                            │ 且使用者按下切換按鈕
                                            ▼
                                     ┌──────────────┐
                                     │  Impedance   │
                                     │  阻抗控制中   │  ← 狀態鎖定，忽略擺桿掉落
                                     └──────┬───────┘
                                            │ 使用者按下「重置系統」
                                            ▼
                                        回到 Swing-up
```

- **Swing-up**：能量法起擺（`control/pendulum.py::swing_up_voltage`），電壓上限
  `SWINGUP_VOLTAGE_LIMIT`（低於平衡/阻抗上限，降低起擺過程對機構的衝擊）。
  切入 Balance 前須同時滿足角度（`PENDULUM_ENGAGE_ANGLE_DEG`）與角速度
  （`PENDULUM_ENGAGE_RATE_RADS`）容許範圍——起擺過程中擺桿每次擺盪都會
  「路過」頂端，但角速度往往高達數十 rad/s，只看角度會誤判為已平衡而過早
  切入 LQR，導致 LQR 以飽和電壓對抗高速擺動、擾亂起擺能量累積，使擺桿
  永遠立不起來。若實測仍擺不上去，可調高 `SWINGUP_GAIN` / `SWINGUP_VOLTAGE_LIMIT`
  加大起擺力道，或調寬 `PENDULUM_ENGAGE_RATE_RADS` 讓 LQR 更早接手。
- **Balance**：LQR 平衡（`BALANCE_K`，已於實體 QUBE-Servo 3 驗證），
  電壓上限 `PENDULUM_VOLTAGE_LIMIT`。
- **Impedance**：切換瞬間記錄旋臂當下角度為新平衡點 `theta_d`，並以
  `BUMPLESS_TRANSFER_CYCLES` 個週期將電壓由平衡控制輸出線性過渡至阻抗控制輸出。
  進入後不再對擺桿角度做任何補償，所有扭矩輸出僅由阻抗控制律與旋臂運動學決定，
  並忽略擺桿掉落狀態，直到使用者按「重置系統」。
- 任一狀態下，`control/safety.py::VoltageStepLimiter` 對每週期電壓變化量設定
  硬性飽和上限（`MAX_VOLTAGE_STEP_PER_CYCLE`），吸收掉落衝擊或切換瞬間的扭矩突變。

所有切換判定角度 / 速度容許範圍、致能所需連續週期數、起擺與平衡增益、
飽和上限皆集中於 `config.py`，可依實際硬體系統辨識結果調整。

## 控制參數說明

| 參數 | 意義 | 單位 | 預設值 |
|------|------|------|--------|
| K | 虛擬剛性（越大越硬，越小越軟） | N·m/rad | 1.0 |
| B | 虛擬阻尼（越大收斂越快，過小會振盪） | N·m·s/rad | 0.1 |
| M | 虛擬慣量（越大對衝擊反應越慢） | kg·m² | 0.05 |
| Kp | 內迴路比例增益 | — | 20.0 |
| Kd | 內迴路微分增益 | — | 0.5 |
| θ_d | 目標角度 | rad | 0.0 |

**穩定條件**：B² ≥ 4MK（臨界阻尼），GUI 會自動提示是否欠阻尼。

## 外力估算原理

不使用額外的力感測器，透過電流估算外力扭矩：

```
τ_ext = Kt × I − (J × α + Bf × ω)
```

- `Kt × I`：馬達輸出扭矩
- `J × α`：慣性扭矩
- `Bf × ω`：摩擦扭矩
- `τ_ext`：估算的外部力矩

精度受到 Kt、J、Bf 辨識準確度的影響。

## 安全機制

| 項目 | 限制值 | 觸發後果 |
|------|--------|---------|
| 角度 | ±270° | 緊急停止 |
| 速度 | ±50 rad/s | 緊急停止 |
| 電流 | >4.0 A | 緊急停止 |
| 外力估算 | >1.0 N·m | 本週期外力歸零（不停止） |
| 暖機期 | 前 50 個週期（100ms） | 電流/外力檢查暫停 |
| 起擺電壓 | ±3.0 V | 飽和（降低起擺衝擊） |
| 平衡電壓 | ±15.0 V | 飽和（沿用原 balance_control_qube.py 已驗證上限） |
| 電壓步階 | ±1.0 V / 週期 | 飽和（吸收掉落衝擊 / 切換瞬間扭矩突變） |

「■ 停止」按鈕在任何狀態下皆為最高優先權，點擊後立即將馬達電壓設為 0。

## 馬達 / 擺桿參數修改

所有硬體常數集中在 `config.py`，系統辨識後直接修改即可：

```python
Kt         = 0.042      # 力矩常數   [N·m/A]
J_motor    = 4.0e-6    # 轉子慣量   [kg·m²]
B_friction = 1.0e-5    # 黏性摩擦   [N·m·s/rad]

PENDULUM_MASS   = 0.024   # Mp 擺桿質量 [kg]
PENDULUM_LENGTH = 0.129   # Lp 擺桿長度 [m]
BALANCE_K = np.array([-1.2247, 24.9044, -0.6877, 3.1321])  # LQR 平衡增益
```

> **注意**：起擺律與能量函式現在逐項對應 Åström & Furuta (1996,
> *Swinging Up a Pendulum by Energy Control*) 的 Eq. 2 / Eq. 8，
> `SWINGUP_DIRECTION_SIGN` 預設 `1.0` 即為文獻公式的直接對應，純粹是
> 硬體極性修正項。僅當實體硬體編碼器 / 馬達接線極性相反、導致起擺方向
> 錯誤時才需改為 `-1.0`。
